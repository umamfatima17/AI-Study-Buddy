# AI Study Buddy

A simple rule-based study assistant made using Python.

## About the Project

AI Study Buddy is a beginner-friendly Python chatbot that can help with basic study-related questions.

It gives responses based on keywords and can also tell the current time and date.

## Features

- Gives study tips
- Provides exam preparation advice
- Gives motivation
- Helps with focus and stress
- Tells current time
- Tells today's date
- Greets the user according to the time
- Handles basic conversations
- Exit using `bye`, `exit` or `quit`

## Technologies Used

- Python
- datetime module
- Dictionary
- Functions
- Loops
- Conditional statements
- String handling

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:
    python  study_buddy.py
5. Enter your name and start chatting with Study Buddy.

## Example

Welcome to Study Buddy! Enter your name: Umam

Good Evening, Umam!

Umam: study tip

Study Buddy: Try studying for 25 minutes and then take a 5-minute break.
